# 验收指标

“提升类”指标需项目方提供统一基线与统计口径；代码与测试只按获批口径计算。

| 技术 | 必测场景 | PPT 指标 |
|---|---|---|
| 1.1 | 状态变化、告警、语音/文字指令、异常切换 | 结构化指令成功率 ≥95%；异常切换 ≤500 ms |
| 1.2 | 多任务并发、突发高优先级、原任务恢复、低电量 | 多任务成功率 92.3%；抢占 ≤500 ms |
| 1.3 | 钢格网/坡道/楼梯/窄通道，仿真到实机 | 复杂地形通行率 >90%；实机迁移 96.8% |
| 1.4 | 46 cm 机器人过 75 cm 通道 | 稳定通行；能力 +25%；改造成本 -90% |
| 1.5 | 钢格网振动、长距离巡检 | 异常率 -85%；均速 ≥0.8 m/s；单次 2 km |
| 1.6 | 钢格网楼梯、弱纹理、激光退化 | 定位精度 ±2 cm |
| 1.7 | BIM 与 SLAM 对齐、检测事件定位 | 厘米级映射；位置报告准确率 ≥98% |
| 1.8 | 0.8 m/s 行进、±60°、1–5 m、不同辐射率 | 范围内偏差 ≤0.2 ℃；动态 ±0.5 ℃；效率 +10 倍 |
| 1.9 | 85 dB 背景噪声、典型故障样本 | SNR 15–20 dB；识别准确率 75% |

阈值集中保存在 `ros2_ws/src/inspection_bringup/config/acceptance_thresholds.yaml`，代码不得另设验收口径。
