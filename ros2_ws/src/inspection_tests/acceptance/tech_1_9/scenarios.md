# 技术 1.9 验收场景（定向声纹早期诊断）

## 场景

- S1：85 dB 背景噪声 + 无故障样本
- S2：85 dB 背景噪声 + 典型故障样本（轴承 / 齿轮 / 松动）
- S3：波束方向扫描（0° / ±30° / ±60°）
- S4：8 路麦克风任一路失效
- S5：波束形成音频帧 → Python 模型推理链路（`/acoustic_mono` → `/acoustic_diagnosis` 回填）

## 判定

- 输出 SNR 落在 15–20 dB
- 典型故障识别准确率 ≥75%

## 边界说明

- 未装载声纹模型、或音频帧过期（>1 s）时不推理、不回填 `fault_class`；
- 已带故障类别的消息（含本节点回填结果）不再二次推理，避免同话题自激；
- 判定为故障时另发 `/inspection_alert`（`pose_valid=false`），由 1.7 判「未定位」；
- C++ 侧当前音频为**合成示例波形**（未接真实麦克风阵列），SNR 与波束结果不得
  作为实测指标引用；接入真实阵列后本边界自动解除。
